A distinct **Sol** model was attempted but rejected by the configured Local Codex ceiling (`model_ceiling_exceeded`, ceiling Luna); it produced no solution. Thus these trials use **one model with two effort settings**, and only the high-effort trial reached completion.

Both were initialized from the same public frozen source and asked to solve [TASK.md](../TASK.md), without network access. Public reference-code exposure remains a risk; the completed trial's local-memory access is a documented protocol violation. Do not present these as a validated cross-model performance study.

```sh
node benchmarks/worktree-admission/grade.mjs \
  --candidate /absolute/path/to/patched-source \
  --label gpt-6-luna-high \
  --result-kind model_run
```
